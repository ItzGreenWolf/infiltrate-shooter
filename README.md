# Infiltrate

**2D Top-Down Building Infiltration Shooter**

Clear all hostiles in each building. 5 levels of increasing difficulty.

## How to Run (Zero Coding Required)

1. Make sure you have Python 3 installed.
2. Open a terminal in this folder (or after cloning the repo).
3. Run these two commands:

```bash
pip install -r requirements.txt
python main.py
```

That is all. The game will open immediately.

## Controls

| Key / Input       | Action                          |
|-------------------|---------------------------------|
| **WASD** or **Arrow Keys** | Move                     |
| **Mouse**         | Aim                             |
| **Left Mouse Button** | Shoot / Use current weapon  |
| **1**             | Pistol                          |
| **2**             | Assault Rifle                   |
| **3**             | Knife (melee)                   |
| **4**             | Grenade (throw)                 |
| **5**             | C4 (place)                      |
| **F**             | Detonate all placed C4          |
| **R**             | Restart level (after death)     |
| **Space / Enter** | Proceed to next level           |
| **ESC**           | Quit                            |

## Weapons

1. **Pistol** – Accurate, solid damage, semi-auto
2. **Assault Rifle** – High fire rate, full-auto
3. **Knife** – High damage melee, infinite
4. **Grenade** – Throwable explosive (limited)
5. **C4** – Placeable charge, detonate with F (limited)

## Objective

Kill every hostile in the level. When the last one drops you will see:

**LEVEL CLEARED**  
Press Space or Enter to proceed to the next level.

Complete all 5 levels to finish the mission.
